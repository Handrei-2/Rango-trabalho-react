# Rangô

App mobile em React Native (Expo) que sorteia o que comer. A cada toque no botão, escolhe um prato aleatório, troca a imagem e mostra um link para a receita.

## Conceitos aplicados
- Classe `App` com `extends Component` e `constructor`
- `this.state` e `this.setState()`
- Array de 8 pratos
- `Math.random()` e `Math.floor()`
- Evento `onPress` com `TouchableOpacity`
- `Image` que muda após a interação
- `StyleSheet.create()`

## Como rodar
1. `npm install`
2. `npx expo start`
3. Escaneie o QR code com o app Expo Go
